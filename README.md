# F1_Calculate工具

## 项目概述
这是一个用于计算文本语义相似度的工具，使用语义F1值作为评价指标。该工具考虑了词语的同义关系，能够更准确地评估文本的语义相似度。

## 特点
- 使用哈工大同义词词林进行同义词处理
- 支持中文分词
- 考虑词语的语义相似度
- 生成Excel格式的输出文件

## 语义F1值计算方法

### 1. 基本思路
语义F1值的计算基于以下几个核心概念：
- 词语匹配：考虑完全匹配、同义词匹配和字符重叠
- 词语类型：根据词林编码判断词语类型（动词、名词、形容词等）
- 匹配分数：不同匹配类型有不同的分数权重

### 2. 计算步骤

1) **分词预处理**
   - 使用分词工具将文本分割成词语序列
   - 对每个词语获取其词林编码和类型

2) **词语匹配分数计算**
   ```
   matchScore = 
   {
     1.0                    // 完全相同的词
     0.9                    // 同义词
     0.8 * 字符重叠度        // 字符重叠（相似词）
     0.0                    // 无关词
   }
   ```

3) **词语类型加权**
   - 同类型词语匹配时得分提升10%
   - 词语类型根据词林编码判断：
     - A/B/C类：名词（名词、时间词、处所词等）
     - D/E/F类：动词（动词、行为词等）
     - G/H类：形容词（形容词、状态词等）
     - K类：副词

4) **最终语义F1值计算**
   ```
   精确率 = 匹配分数总和 / 预测文本词语数
   召回率 = 匹配分数总和 / 标准答案词语数
   语义F1 = 2 * (精确率 * 召回率) / (精确率 + 召回率)
   ```

### 3. 示例
标准答案："这个苹果很好吃"
预测文本："这个水果非常美味"

分词后：
- 标准答案：["这个", "苹果", "很", "好吃"]
- 预测文本：["这个", "水果", "非常", "美味"]

匹配情况：
- "这个" -> "这个"：完全匹配，分数1.0
- "苹果" -> "水果"：同义词，分数0.9
- "很" -> "非常"：同义词，分数0.9
- "好吃" -> "美味"：同义词，分数0.9

计算：
```
精确率 = (1.0 + 0.9 + 0.9 + 0.9) / 4 = 0.925
召回率 = (1.0 + 0.9 + 0.9 + 0.9) / 4 = 0.925
语义F1 = 2 * (0.925 * 0.925) / (0.925 + 0.925) = 0.925
```

## 位置感知F1值计算方法

### 1. 基本思路
位置感知F1值在语义F1值的基础上，进一步考虑了词语在句子中的相对位置。它基于以下假设：
- 相同或相似的词语如果位置接近，其语义相似度应该更高
- 不同类型的词语对位置的敏感度不同（如动词位置相对固定，副词位置较为灵活）

### 2. 词语位置计算
1) **相对位置计算**
   ```
   相对位置 = 词语在句子中的位置 / 句子总长度
   ```
   例如：在5个词的句子中，第2个词的相对位置为 2/5 = 0.4

2) **位置容忍度**
   不同词语类型有不同的位置容忍度：
   ```
   容忍度 = {
     动词：   0.3  // 位置相对固定
     名词：   0.4  // 位置较为灵活
     形容词： 0.5  // 位置更灵活
     副词：   0.6  // 位置最灵活
     其他：   0.4  // 默认容忍度
   }
   ```

3) **位置分数计算**
   ```
   位置差异 = |原文位置 - 预测文位置|
   
   如果 位置差异 <= 容忍度：
       位置分数 = 1.0 - (位置差异/容忍度) * 0.2
   否则：
       位置分数 = exp(-1.5 * (位置差异-容忍度)²)
   ```

### 3. 最终分数计算
1) **词语匹配分数**
   - 完全匹配：1.0
   - 同义词匹配：0.9
   - 字符重叠（相似词）：0.8 * 重叠度
   - 同类型词语额外加分：匹配分数 * 1.1

2) **位置感知分数**
   ```
   单词对最终分数 = 词语匹配分数 * 位置分数
   总分 = 所有匹配词对分数之和
   位置感知F1 = 2 * (位置感知精确率 * 位置感知召回率) / (位置感知精确率 + 位置感知召回率)
   ```
   其中：
   ```
   位置感知精确率 = 总分 / 预测文本词语数
   位置感知召回率 = 总分 / 标准答案词语数
   ```

### 4. 示例
标准答案："我很喜欢吃苹果"
预测文本："我非常爱吃水果"

分词后（带位置）：
- 标准答案：["我"(0/4), "很"(1/4), "喜欢"(2/4), "吃"(3/4), "苹果"(4/4)]
- 预测文本：["我"(0/4), "非常"(1/4), "爱"(2/4), "吃"(3/4), "水果"(4/4)]

匹配分析：
1. "我" -> "我"：
   - 完全匹配：1.0
   - 位置相同：1.0
   - 最终分数：1.0 * 1.0 = 1.0

2. "很" -> "非常"：
   - 同义词：0.9
   - 位置相同：1.0
   - 最终分数：0.9 * 1.0 = 0.9

3. "喜欢" -> "爱"：
   - 同义词：0.9
   - 位置相同：1.0
   - 同为动词加分：0.9 * 1.1 = 0.99
   - 最终分数：0.99 * 1.0 = 0.99

4. "吃" -> "吃"：
   - 完全匹配：1.0
   - 位置相同：1.0
   - 同为动词加分：1.0 * 1.1 = 1.1
   - 最终分数：1.1 * 1.0 = 1.1

5. "苹果" -> "水果"：
   - 同义词：0.9
   - 位置相同：1.0
   - 同为名词加分：0.9 * 1.1 = 0.99
   - 最终分数：0.99 * 1.0 = 0.99

计算：
```
总分 = 1.0 + 0.9 + 0.99 + 1.1 + 0.99 = 4.98
位置感知精确率 = 4.98 / 5 = 0.996
位置感知召回率 = 4.98 / 5 = 0.996
位置感知F1 = 2 * (0.996 * 0.996) / (0.996 + 0.996) = 0.996
```

## 使用说明
1. 确保已安装Go语言环境（1.20+）
2. 确保`data/cilin.txt`文件存在
3. 运行程序：
   ```bash
   go run main.go
   ```
4. 按提示输入要比较的文本
5. 程序会输出相似度结果

## 输出说明
1. 程序会生成Excel文件，包含以下信息：
   - 标准答案文本
   - 预测文本
   - 语义F1值
2. 输出文件说明：
   - 文件名包含生成时间戳，格式为：年-月-日_时-分-秒
   - 例如：`output_2025-01-13_11-18-31.xlsx`

## 词林说明

本程序使用哈工大同义词词林扩展版（`data/cilin.txt`）作为同义词词典。词林的格式为：

```
编码 词语1 词语2 词语3 ...
```

其中编码表示词语的类目分类，具有相同编码的词语为同义词。例如：

```
Aa01A01= 人 士 人物 人士 人氏 人选
```

这表示"人、士、人物、人士、人氏、人选"都属于同一个意义类别。

## 注意事项

1. 确保词林文件（cilin.txt）格式正确
2. 运行前请确认有写入output.xlsx文件的权限
3. 词林文件的编码必须是UTF-8格式
