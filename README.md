# 同义词处理工具

## 项目概述
这是一个用于处理同义词的Go语言工具，可以将同义词数据转换为Excel格式输出。

## 主要功能
- 读取同义词词典（JSON格式）
- 处理同义词数据
- 生成Excel格式的输出文件

## 文件说明
### 输入文件
- `data/synonym_dict.json`：同义词词典文件，JSON格式
- 示例结构：
```json
{
  "word": ["synonym1", "synonym2"]
}
```

### 输出文件
- `output.xlsx`：生成的Excel文件，包含处理后的同义词数据

## 使用说明
1. 确保已安装Go语言环境（1.20+）
2. 配置同义词词典文件（data/synonym_dict.json）
3. 运行程序：
```bash
go run main.go
```
4. 程序运行后会在当前目录生成output.xlsx文件

## 开发环境要求
- Go 1.20+
- Excel库依赖（已在go.mod中配置）

## 注意事项
1. 确保同义词词典文件格式正确
2. 运行前请确认有写入output.xlsx文件的权限
3. 如果output.xlsx已存在，会被覆盖
