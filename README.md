# 同义词处理工具

## 项目概述
这是一个用于计算f1分数的Go语言工具，可以将f1分数转换为Excel格式输出。

## 主要功能
- 计算f1分数
- 生成Excel格式的输出文件

## 文件结构

```
F1_Calculate/
├── data/
│   └── cilin.txt         # 哈工大同义词词林
├── main.go               # 主程序代码
├── go.mod               # Go模块文件
├── go.sum               # Go依赖版本文件
└── README.md            # 项目说明文档
```

## 使用说明
1. 确保已安装Go语言环境（1.20+）
2. 确保`data/cilin.txt`文件存在
3. 运行程序：
   ```bash
   go run main.go
   ```
4. 按提示输入要比较的文本
5. 程序会输出相似度结果

## 输出说明
1. 程序会生成Excel文件，包含以下信息：
   - 输入的两段文本
   - F1值、精确率、召回率
   - 语义相似度F1值
   - 位置感知F1值
2. 输出文件说明：
   - 文件名包含生成时间戳，格式为：年-月-日_时-分-秒
   - 例如：`output_2025-01-13_11-18-31.xlsx`

## 词林说明

本程序使用哈工大同义词词林扩展版（`data/cilin.txt`）作为同义词词典。词林的格式为：

```
编码 词语1 词语2 词语3 ...
```

其中编码表示词语的类目分类，具有相同编码的词语为同义词。例如：

```
Aa01A01= 人 士 人物 人士 人氏 人选
```

这表示"人、士、人物、人士、人氏、人选"都属于同一个意义类别。

## 注意事项

1. 确保词林文件（cilin.txt）格式正确
2. 运行前请确认有写入output.xlsx文件的权限
3. 词林文件的编码必须是UTF-8格式
